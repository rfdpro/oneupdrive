Office

            
Double-click with AutoSave

            

                

                    
Let OneUpDrive open Office filesWord, Excel and PowerPoint files in OneUpDrive's folders open from OneDrive with AutoSave. Other files open as usual. Turn this on, then choose OneUpDrive in Default apps.

                    

                

                    
Default program

            

            
Open with AutoSave

            

                

                    
Open a file from OneDriveOffice saves to OneDrive as you work, and others can edit with you. Also in File Explorer: right-click > OneUpDrive > Open with AutoSave. Office must use the same Microsoft account.

                    

            

            
Leave folders to the OneDrive app

            

                

                    
OneUpDrive skips these folders so the OneDrive app can sync them with AutoSave (in the OneDrive app: Settings > Account > Choose folders).

                    

                    

                    

                

            

            

            
Experimental

            

                

                    
Tell Office about OneUpDrive's foldersRegisters OneUpDrive as Microsoft documents for sync apps. Office ignored it when tried (October 2026). Turning it off removes everything it set.
