# OneUpDrive user guide

Welcome! This guide is for everyone, not just developers.

> **Where things stand:** OneUpDrive is in beta. The pages below describe the app as it works today. If something looks wrong, see [When something goes wrong](troubleshooting.md) and report it.

**Start here**
* [Getting started](getting-started.md): installing, setting up, what you'll need
* [Words used in this guide](glossary.md): what "online-only", "safety stop" and "folder pair" mean
* [The settings window](settings-window.md): every setting, page by page
* [The OneUpDrive icon](tray-icon.md): status at a glance, pausing, and the questions OneUpDrive asks you
* [File Explorer](explorer.md): the navigation-pane entry, status icons and the right-click menu

**How it works**
* [Syncing in depth](syncing.md): what happens to deleted and conflicting files, safety stops, the ransomware guard, getting files back
* [Choosing what syncs](excluding-files.md): leaving out `node_modules`, temp files, huge videos…
* [Files On-Demand and freeing space](files-on-demand.md): online-only files, freeing space by itself, your largest files
* [Finding files](search.md): search all of OneDrive by name, online-only files too, from the window, a hotkey or `oneup find`
* [More folders, backups, shared folders and accounts](folders.md): any folder with any OneDrive folder, one-way backups, your Desktop and Documents, folders others shared, several accounts
* [Earlier versions and sharing](versions-and-sharing.md): getting an older version back, sharing links
* [Office](office.md): AutoSave and editing together in Word, Excel and PowerPoint
* [Encrypted vaults](vaults.md): folders only you can read, compatible with Cryptomator (experimental)
* [Moving over from the OneDrive app](migrating-from-onedrive.md): switching without re-downloading everything
* [Scripts and hooks](hooks.md): watching what OneUpDrive does, starting your own programs when something happens, PowerShell

**When you need help**
* [When something goes wrong](troubleshooting.md): what each problem means, and how to fix it if retrying doesn't
* [FAQ](faq.md)

Everything in the settings window also has an `oneup` command, for scripts and people who like a terminal; the pages show both.
